📞 TROUBLESHOOTING:

Issue: Frontend returns 403 Forbidden
→ S3 bucket has public access enabled (resolved)

Issue: API calls fail with 401
→ Ensure Cognito is properly configured in aws-exports.js
→ User must be authenticated first

Issue: Lambda timeout on predictions
→ Claude Sonnet sometimes takes >120s for complex requests
→ Increase Lambda timeout in template.yaml and redeploy

Issue: Slow response times
→ First request hits Lambda cold start (~10-30s) - normal
→ Subsequent requests should be faster (~1-3s)
→ Consider CloudFront distribution for frontend caching

Issue: CORS errors
→ Already enabled in API Gateway
→ Check browser console for specific error
