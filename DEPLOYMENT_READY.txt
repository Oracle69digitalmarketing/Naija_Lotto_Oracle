================================================================================
  QUICK DEPLOYMENT STEPS
================================================================================

1. Prerequisites:
   - AWS Account with credentials configured
   - AWS CLI installed
   - SAM CLI installed
   - Bedrock Claude 3.5 Sonnet access enabled

2. Configure AWS:
   export AWS_PROFILE=naija-lotto
   # or
   export AWS_ACCESS_KEY_ID=...
   export AWS_SECRET_ACCESS_KEY=...
   export AWS_DEFAULT_REGION=eu-central-1

3. Deploy Backend:
   ./deploy.sh

4. Update Frontend:
   - Copy API endpoint from deployment output
   - Update aws-exports.js with the endpoint
   - npm run build

5. Deploy Frontend:
   - Upload dist/ to S3
   - Set up CloudFront distribution
   - Or use AWS Amplify: amplify publish

================================================================================
  IMPORTANT NOTES
================================================================================

1. Before deploying, ensure:
   - Bedrock Claude 3.5 Sonnet access is enabled in eu-central-1
   - AWS credentials have proper IAM permissions
   - Region is set to eu-central-1

2. API Authentication:
   - API Gateway uses Cognito User Pool authentication
   - Update Cognito configuration in aws-exports.js
   - Users must be authenticated before using the API

3. Lambda Cold Starts:
   - First invocation might take 10-30 seconds
   - Subsequent invocations are much faster
   - Consider provisioned concurrency for production

4. Cost Management:
   - Set up CloudWatch alarms for unexpected usage
   - Monitor Bedrock API token consumption
   - Review CloudFormation stack for unused resources
